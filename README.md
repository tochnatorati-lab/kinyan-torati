# קִנְיַן תּוֹרָתִי

תוכנה לחזרה ושינון של הלימוד התורני, שעובדת גם בלי אינטרנט.

**להורדה:** [kinyan-torati.zip](https://github.com/tochnatorati-lab/kinyan-torati/raw/main/kinyan-torati.zip)

**למשתמשי נטפרי:** [kinyan-torati.zip (מהדורת נטפרי)](https://github.com/tochnatorati-lab/kinyan-torati/raw/main/netfree/kinyan-torati.zip) — מביאה את הטקסטים רק מספריית אוצריא, ומתעדכנת בנפרד מתיקיית `netfree`.

מחלצים את התיקייה למקום קבוע במחשב ולוחצים על "הפעל תוכנה". עדכונים מגיעים מכאן לבד: כשיוצאת גרסה חדשה, התוכנה שואלת בפתיחה אם לעדכן, והכרטיסיות וההגדרות נשמרות.

לכל הערה או בקשה: tochnatorati@gmail.com

---
הקבצים כאן: `chazara.html` (התוכנה עצמה), `version.json` (מספר הגרסה האחרונה, שממנו התוכנה יודעת שיש עדכון), `kinyan-torati.zip` (החבילה המלאה להתקנה).
